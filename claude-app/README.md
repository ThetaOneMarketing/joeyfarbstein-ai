# Claude app (claude.ai) edition

Same as the ChatGPT quick look. Claude searches the person's past chats itself, so there's no export.

1. Copy `quick-look-prompt.md`, all of it.
2. Paste into a new chat at claude.ai on a computer. Send.
3. Download the report it makes, open it in a browser, click **Send to Joey** at the top.

If Claude says it can't search past chats: Settings > turn on "Search and reference chats."

Claude Code users don't need this; they install the plugin (see the main README).
